# 💰 sitedesp - Controle de Despesas

Uma aplicação web desenvolvida em Django para gerenciamento e organização de despesas pessoais.

## 🚀 Funcionalidades
- Cadastro e exclusão de despesas.
- Categorização de gastos.
- Visualização de relatórios (se houver).

## 🛠️ Tecnologias Utilizadas
- **Backend:** Python / Django
- **Banco de Dados:** SQLite
- **Frontend:** HTML, CSS, JavaScript

## 📦 Como Executar o Projeto

1. Clone o repositório:
`git clone https://github.com/Gabrielvini20001/sitedesp.git`

2. Instale as dependências (se tiver um requirements.txt):
`pip install -r requirements.txt`

3. Execute as migrações:
`python manage.py migrate`

4. Inicie o servidor:
`python manage.py runserver`
